# Access model

ระบบนี้ใช้บัญชีส่วนกลางและบัญชีจังหวัดแยกจากจังหวัดข้อมูล

- ผู้ใช้จังหวัดดู Dashboard และ Export รวมทุกจังหวัดได้
- ผู้ใช้จังหวัดบันทึกข้อมูลได้เฉพาะจังหวัดของตัวเอง
- ผู้ใช้ส่วนกลางดูและ Export รวมทุกจังหวัดได้ และสามารถเลือกจังหวัดสำหรับบันทึกข้อมูลได้

จังหวัดข้อมูลมี 4 จังหวัด ได้แก่ นครปฐม ราชบุรี สมุทรสาคร และสมุทรสงคราม
