# 🥥 ระบบเก็บข้อมูลมะพร้าวน้ำหอม 4 จังหวัด

ระบบ Google Apps Script สำหรับเก็บข้อมูลคุณภาพมะพร้าวน้ำหอมใน 4 จังหวัด:
**นครปฐม · ราชบุรี · สมุทรสาคร · สมุทรสงคราม**

## โครงสร้างข้อมูล (อ้างอิงจากแบบเก็บข้อมมูล.xlsx)

| คอลัมน์ | หัวข้อ | คำอธิบาย |
|---------|--------|----------|
| A | ลำดับ | 1-20 อัตโนมัติ |
| B | แปลงที่ | 1-10 |
| C | ทะลายที่ | 1-2 ต่อแปลง |
| D | จำนวนผลผลิต/ทะลาย | **= E+F+G (คำนวณอัตโนมัติ)** |
| E | จำนวนผลคุณภาพ | กรอกเอง |
| F | จำนวนผลตํ่ากว่าเกณฑ์ | กรอกเอง |
| G | จำนวนผลเสีย | หัวทุย / ผลแตก / อื่นๆ |
| H | นํ้าหนักผลเฉลี่ย (กก.) | กรอกเอง |
| I | เส้นรอบวงเฉลี่ย (ซม.) | กรอกเอง |
| J | หมายเหตุ | กรอกเอง |

> **10 แปลง × 2 ทะลาย = 20 แถวข้อมูล ต่อ 1 จังหวัด**

## วิธีติดตั้ง

### 1. สร้าง Google Sheet ใหม่
- ไปที่ [sheets.google.com](https://sheets.google.com)
- คลิก **+** สร้าง spreadsheet เปล่า

### 2. เปิด Apps Script Editor
- เมนู: **Extensions > Apps Script**
- ลบโค้ดเดิมทั้งหมดใน `Code.gs`

### 3. วางโค้ด
- **Code.gs** → วางเนื้อหาจากไฟล์ `Code.gs` ใน editor
- **Sidebar.html** → คลิก **+** ข้าง Files → เลือก **HTML** → ตั้งชื่อ `Sidebar` → วางเนื้อหาจาก `Sidebar.html`
- คลิก **💾 Save** (Ctrl+S)

### 4. รันครั้งแรก (Authorization)
- รีโหลด Google Sheet
- จะเห็นเมนู **🥥 จัดการข้อมูลมะพร้าว**
- คลิก **📋 ตั้งค่าเริ่มต้น (สร้างแผ่นทั้งหมด)**
- หน้าจอขอสิทธิ์ → เลือกบัญชี Google → **Advanced** → **Go to [project] (unsafe)** → **Allow**
- รอสักครู่ ระบบจะสร้างแผ่นให้ครบ 6 แผ่น

### 5. เริ่มใช้งาน
- ใช้เมนู **✏️ กรอกข้อมูล (Sidebar)** เพื่อเปิดฟอร์มกรอกข้อมูล
- หรือกรอกโดยตรงในแผ่นจังหวัด (คอลัมน์ E-J)
- ระบบคำนวณ D = E+F+G อัตโนมัติ
- แถวที่ %คุณภาพ < 50% จะขึ้นสีแดง

## ฟีเจอร์

| เมนู | ฟังก์ชัน |
|------|----------|
| 📋 ตั้งค่าเริ่มต้น | สร้างแผ่น นครปฐม ราชบุรี สมุทรสาคร สมุทรสงคราม + สรุปภาพรวม + ตั้งค่า |
| ✏️ กรอกข้อมูล (Sidebar) | เปิดฟอร์มข้างจอ กรอกข้อมูลทีละแปลง/ทะลาย |
| 📊 สรุปภาพรวม 4 จังหวัด | คำนวณ %คุณภาพ นํ้าหนักเฉลี่ย เส้นรอบวงเฉลี่ย ทุกจังหวัด |
| 🔍 ตรวจสอบข้อมูลทั้งหมด | ตรวจค่าติดลบ ข้อมูลขาดหาย ทั้ง 4 จังหวัด |

## การทำงานอัตโนมัติ (onEdit)

- เมื่อกรอก E, F, G → D คำนวณอัตโนมัติ
- เมื่อ %คุณภาพ < 50% → ไฮไลท์แถวสีแดง
- คอลัมน์ A, B, C, D ถูก protect (warning only)

## การแก้ไขค่า Config

ใน `Code.gs` บรรทัดต้นๆ:

```javascript
const CONFIG = {
  provinces: ['นครปฐม', 'ราชบุรี', 'สมุทรสาคร', 'สมุทรสงคราม'],
  maxPlots: 10,        // เปลี่ยนจำนวนแปลงได้
  bunchesPerPlot: 2,   // เปลี่ยนจำนวนทะลายต่อแปลงได้
  // ...
};
```

## การเพิ่มข้อมูลเกิน 10 แปลง

1. แก้ `maxPlots` ใน CONFIG
2. รัน **ตั้งค่าเริ่มต้น** ใหม่ (จะล้างข้อมูลเดิม!)
3. หรือเพิ่มแถวเองด้วยตนเองในแต่ละแผ่นจังหวัด

## Troubleshooting

| ปัญหา | วิธีแก้ |
|-------|--------|
| ไม่เห็นเมนู 🥥 | รีโหลด Google Sheet |
| Sidebar กดบันทึกไม่ไป | เช็คว่าเลือก จังหวัด + แปลง + ทะลาย ครบ |
| D ไม่คำนวณ | ลองแก้ค่า E/F/G ใหม่ trigger ให้ onEdit ทำงาน |
| ตั้งค่าเริ่มต้นแล้วข้อมูลหาย | ตั้งค่าเริ่มต้นจะล้างแผ่น — backup ก่อน |
